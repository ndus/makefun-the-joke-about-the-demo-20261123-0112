This program writes one joke to `<output>/entry.txt`, using `MAKEFUN_OUTPUT_DIR` or `/output`.
The joke: my AI coding partner says "I found the issue" like it didn't just write the issue five minutes ago.
It lands because every pair-programmer with an AI has watched it confidently debug its own code.
